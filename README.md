1. ***Важнейшие команды гита***

    > ЧЕК СТАТУСА
    * Проверить статус репозитория (какие файлы сохранены, изменены):
    ```
    git status
    ```
    > ВЫБОР ЧТО СОХРАНЯТЬ
    * Выбрать ВСЕ изменения файлов ЛОКАЛЬНОГО репозитория (ДЛЯ СОХРАНЕНИЯ):
    ```
    git add .
    ```
    Или выбрать конкретные ЛОКАЛЬНЫЕ файлы (ДЛЯ СОХРАНЕНИЯ):
    ```
    git add <путь_к_файлу1> <путь_к_файлу2>
    ```
    (вместо пути можно имя файла или папки, если лежат в проекте)

    * Убрать файл или папку из сохранения:
    ```
    git restore --staged <имя_файла>
    ```
    ИЛИ:
    ```
    git reset <имя_файла>
    ```

    > ЛОКАЛЬНАЯ ФИКСАЦИЯ
    * Зафиксировать изменения added файлов ЛОКАЛЬНО (Создать коммит):
    ```
    git commit -m "Понятное описание того, что было сделано"
    ```

    > ВЫГРУЗКА НА СЕРВЕР (GITHUB)
    * Отправить изменения в УДАЛЕННЫЙ репозиторий (на GitHub) в ветку main либо другую:
    ```
    git push origin <имя_ветки>
    ```



2. ***Выгрузка существующего проекта на GitHub***

    > СОЗДАНИЕ УДАЛЕННОГО РЕПОЗИТОРИЯ
    * Создать репозиторий на гитхабе (public, .gitignore for C++, README.md), скопировать на него ссылку <URL>.git

    > ВЫБОР ПУТИ В BASH
    * Открыть директорий с проектом через GitBash (change directory):
    ```
    cd /C/Users/Maxim/sourse/repos/<имя_проекта>
    ``` 

    > ИНИЦИАЛИЗАЦИЯ ГИТА
    * Проинициализировать гит:
    ```
    git init
    ```

    > ПРИКРЕПЛЕНИЕ К ЛОКАЛЬНОМУ УДАЛЕННОГО РЕПОЗИТОРИЯ
    * Закрепить за папкой проекта репозиторий на GitHub:
    ```
    git remote add origin <URL>.git
    ```

    > ПЕРЕИМЕНОВАНИЕ ВЕТКИ
    * Если текущая рабочая ветка называется master, переименовать в новом стиле (main):
    ```
    git branch -M main
    ```
  


3. ***Подтягивание с GitHub***

    > ДОБАВЛЕНИЕ .md и .gitignore К ЛОКАЛЬНОМУ РЕПОЗИТОРИЮ
    * Подтянуть с GitHub файлы .gitignore и README.md:
    ```
    git pull origin <имя ветки>
    ```
    *P.S. На данном этапе лучше внести корректную информацию в .gitignore и README.md.*

    > СКАЧИВАНИЕ УДАЛЕННОГО РЕПОЗИТОРИЯ С ГИТХАБА НА ЛОКАЛКУ
    * Копировать проект с сервера себе на комп
    ```
    git clone <URL>.git
    cd <имя репозитория>
    ```



4. ***Разработка***

    > СОЗДАНИЕ ВЕТКИ
    * Создать ответвление от основы, чтобы независимо его редактировать:
    ```
    git branch dev
    ```

    > ПЕРЕХОД В ВЕТКУ
    * Оказаться в ответвлении:
    ```
    git checkout dev
    ```
    * Создать ветку и сразу перейти в нее:
    ```
    git checkout -b dev
    ```



5. ***Дополнительно***
    > Если git на устройстве настраивается впервые, появится предупреждение и потребуются команды:
    ```
    git config --global user.name "Имя Ф."
    git config --global user.mail "email@mail.ru"
    ```
